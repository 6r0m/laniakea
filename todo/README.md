# todo

Transient implementation plans and investigations. Each task file owns its scope, decisions, progress and verification.

This README explains the lifecycle only. It contains no task list or links to individual plans.

Active task files live directly in this directory. Before closing one, record its outcome, verification and remaining
limitations, and move lasting contracts, decisions and operational knowledge to their stable owner.

Move completed task files into `done/` and mark them DONE. Preserve their decision and execution history; do not delete
a completed plan as part of closure. Rebase relative links when moving it.

The done archive is historical execution context, not a source of current architecture or standing instructions.
Durable documentation and live code remain independent of all task files, including archived ones.
Completing or moving a task requires no task-list update here.
